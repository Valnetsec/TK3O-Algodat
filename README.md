# TK3O-Algodat

A Java group project to practice Abstract Data Types (ADT), inheritance, and linked list implementations.

### Planned Features
- Character using a doubly linked list
- Material shop using a circular linked list
- Limited material stock and periodic stock refresh
- Interactive terminal menu using `Scanner`

- Java
